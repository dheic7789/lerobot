## 一、项目概述

本项目使用六颗 SCS215 串行总线舵机搭建六自由度机械臂，完成第四周 1.1、1.2、2.1
三项功能（2.2 视觉控制因缺少摄像头硬件，本次未完成、不提交）：

1. 1.1 多关节连续控制：预设姿态切换、预设动作序列，并可设置切换时间与速度。
2. 1.2 逆运动学控制（IK）：用键盘 / 文字命令控制末端前后、左右、上下直线运动。
3. 2.1 语音控制：语音识别成文本，再解析成机械臂动作并执行。
4. 2.2 视觉控制：因硬件条件不足未能完成，详见第五节。

硬件：SCS215 舵机 × 6，USB 转串口控制板，串口默认 `COM5`，波特率 `1,000,000`。
软件：Windows + Python 3，仅依赖 `pyserial`（语音部分另需语音识别和 LLM 相关库）。

## 二、1.1 多关节连续控制

### 实现原理

1. 每个关节在 `joint_ranges.json` 中保存实测安全范围 `[min_step, max_step]`。
2. 预设姿态保存到 `joint_poses.json`，每个姿态记录六个舵机的目标步数。
3. 键盘数字键 `1~9` 切换到对应预设姿态。
4. 按 `a` 输入一组数字序列（如 `123`），依次执行多个预设姿态，形成预设动作。
5. 切换时间由 `t` 设置（单位秒），速度寄存器值由 `v` 设置；每个姿态同步下发
   目标位置 + 运动时间 + 速度，实现节奏可控。

### 运行

```powershell
python six_joint_control.py --port COM5
```

按键：`1~9` 切换姿态，`a` 执行动作序列，`t` 设置时间，`v` 设置速度，`q` 退出。

## 三、1.2 逆运动学控制

### 实现原理

本任务的控制量不是「每个关节转多少度」，而是「末端参考点要到哪里」。程序接收
末端目标位置，用逆运动学（Inverse Kinematics，IK）反算出三个主动关节的角度，
再换回舵机步数下发。所以末端能沿前后（x）、左右（y）、上下（z）三个方向走直线。

#### 0）先搞清楚：正运动学与逆运动学

- 正运动学（Forward Kinematics，FK）：已知每个关节转了多少度，求末端夹爪在空间
  中的位置。这是“从关节角到末端位置”的确定性计算。
- 逆运动学（Inverse Kinematics，IK）：反过来，已知希望末端夹爪到达的坐标
  (x, y, z)，求每个关节应该转多少度。这正是 1.2 要回答的问题。

对平面二连杆臂，文档用余弦定理给出了解析解；但本项目是完整 SO101 六关节模型，
含肩部偏置、腕部偏置，解析解比较繁琐，因此我们改用“数值雅可比迭代”。两者的
本质相同：反复算“当前末端离目标还差多少”，再反推“每个关节该往哪个方向微调”。

#### 1）运动学模型：直接用 SO101 的完整连杆链

正运动学使用 `SO101/so101_new_calib.urdf` 的完整连杆链，末端参考点取
`gripper_frame_link`，与 lerobot 的 `RobotKinematics` 默认目标坐标系一致。
连杆链顺序为：

```text
base_link
  -> shoulder_link        shoulder_pan   (ID 1)
  -> upper_arm_link       shoulder_lift  (ID 2)
  -> lower_arm_link       elbow_flex     (ID 3)
  -> wrist_link           wrist_flex     (ID 4)
  -> gripper_link         wrist_roll     (ID 5)
  -> gripper_frame_link   固定末端参考点
```

每个旋转关节的转轴都是其子连杆局部坐标系的 z 轴；关节零位和安装偏置由 URDF
里的 `<origin xyz rpy>` 给出。程序把这张连杆表直接写进代码，运行时不依赖 lerobot。

#### 2）正运动学（FK）：已知关节角，求末端位置

每个连杆的位姿由「父连杆位姿 + 安装偏置 + 关节转角」逐级算出：

```text
R_link = R_parent · R_rpy · Rz(q)
P_link = P_parent + R_parent · xyz
```

其中 `xyz` / `R_rpy` 来自 URDF 的 `<origin>`，`Rz(q)` 是关节绕自身 z 轴的旋转。
从 base_link 连乘到 `gripper_frame_link`，就得到末端在机械臂基座坐标系下的位置
(x, y, z)，单位米（x 前、y 左、z 上）。

#### 3）舵机步数 <-> 关节角换算

SCS215 是 10 位（0~1023）、300° 位置范围的舵机（不是 STS3215 的 12 位 / 360°）。
`joint_ranges.json` 保存每个关节实测的安全范围 `[min_step, max_step]`，取中点
作为该关节的角度零点：

```text
midpoint  = (min_step + max_step) / 2
angle_deg = (step - midpoint) * 300 / 1023
step      = round(angle_deg * 1023 / 300 + midpoint)
```

即「标定中点 = 关节角 0°」，正负方向取决于标定时两个端点输入的先后顺序。

#### 4）逆运动学（IK）：数值雅可比 + 阻尼最小二乘

不使用解析解，采用与 lerobot（placo）一致的数值迭代法：

1. 只解 3 个主动关节：shoulder_pan、shoulder_lift、elbow_flex；wrist_flex、
   wrist_roll 和夹爪保持当前值不动。
2. 用有限差分算「末端位置对关节角」的雅可比矩阵 J（3×3），扰动 eps = 1e-6 rad：

   ```text
   J[i][j] = ( FK(q + eps·e_j) - FK(q) )[i] / eps
   ```

3. 每一步把 J 当作关节角与末端位置的局部线性关系求解：

   ```text
   dq = Jᵀ · ( J·Jᵀ + λ·I )⁻¹ · (target - P)
   ```

   其中 `target - P` 是当前末端到目标的误差向量，λ = 1e-3 为阻尼系数。
4. 限制单步幅度不超过 0.15 rad，并把 q 夹到标定范围对应的关节限位内，
   避免一步跳太远或越界。
5. 反复迭代，最多 120 次；当末端位置误差小于 1e-5 m（0.01 mm）时视为收敛。

#### 5）为什么加阻尼、为什么只解三个关节

- **加阻尼 λ** 是为了应对奇异位形：当机械臂接近伸直时，三个关节的雅可比几乎
  线性相关，纯最小二乘会解出很大的关节速度；阻尼项把解拉向小幅度、稳定的方向，
  避免抖动或失控。
- **只解三个关节** 是因为末端位置只有 3 个自由度，恰好由前三个关节决定；再多解
  就成了欠定问题，解不唯一也不稳定。这样末端走直线时三个关节会同时、协调运动，
  不会出现「只有一个关节转、末端走斜线」的情况。

#### 6）无解与越界处理

每次迭代都把关节角夹在标定范围内；迭代结束后若剩余误差仍大于 5 mm，打印
「IK 无解：目标超出可达范围，已沿原方向移动到最近可达点（本次还差 X cm）」，
并执行这个最接近目标的姿态，而不是直接报错停止。

#### 7）局限说明

- IK 只精确保证每一步的终点位置；两个姿态之间是舵机按 `--duration` 同步插值
  过去，中间路径是关节空间的直线，末端实际轨迹只是接近直线。因此默认步长取
  1 cm 左右，小步移动时肉眼看起来即为直线。
- 夹爪开合（ID 6）不参与 IK，始终保持进入程序时的位置。

### 运行

```powershell
python ik_control.py --port COM5
```

输入 `home / 回中`、`up 0.05`、`forward 0.03`、`left 0.02`、`goto x y z` 等命令。
键盘模式：`python ik_control.py --port COM5 --mode keyboard`。
无需硬件时可先做离线自测：`python ik_control.py --selftest`（数学自测）或
`python ik_control.py --dry-run --move up 0.05`（只预览、不发送指令）。

### 自测结果

- 零位（六关节均在校准中点）末端参考点约为 (0.3914, 0.0000, 0.2265) m。
- 200 个随机点做 FK → IK → FK 往返，最大位置误差 0.000 mm。
- 「向上 5 cm」测试：x、y 位移均为 0.00 cm，z 位移 +5.00 cm，说明末端确实
  沿竖直方向走了直线。

## 四、2.1 语音控制

### 实现原理

1. 用 `faster-whisper` 把麦克风语音转成文本，并打印转录结果。
2. 把繁体字转成简体，避免 Whisper 输出「揮手」而关键词只认「挥手」的问题。
3. 本地关键词优先处理已知命令（回中、姿态、挥手、前后左右上下、夹爪开合等）。
4. 关键词不认识时，调用 DeepSeek（OpenAI 兼容接口）理解整句话，输出目标状态：

   ```json
   {"target_x": 0.42, "target_y": 0.0, "target_z": 0.18, "gripper": "keep"}
   ```

5. 拿到目标位置后，交给 1.2 的逆运动学转成六个舵机步数并执行。

### 运行

```powershell
python voice_control.py --port COM5
```

说「回中」「姿态1」「挥手」「向前移动5厘米」「合上夹爪」等。
文字模式：`python voice_control.py --port COM5 --mode text`。
