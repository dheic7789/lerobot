# 2.1 语音控制实现说明

## 一、任务目标

通过语音识别把语音指令转成文本并打印，再用关键词匹配让机械臂执行对应动作。
动作包括：预设姿态、预设动作、末端前后 / 左右 / 上下移动。

## 二、实现流程

1. 麦克风收音。
2. 语音识别模型把语音转成文本（默认 Google 中文，`zh-CN`），终端打印转录文本。
3. 关键词匹配：
   - 「姿态1」「姿势3」「回到姿态5」 -> 切换到 `joint_poses.json` 里对应姿态。
   - 「挥手」「执行动作 1 2 3」 -> 按姿态序列依次执行。
   - 「向前移动5厘米」「向上」「左移2厘米」 -> 调用 1.2 的逆运动学让末端直线移动。
   - 「合上夹爪」「打开夹爪」 -> 控制第 6 个舵机（夹爪）闭合 / 张开。
   - 「停下」「停止」 -> 不再发送新的运动目标。

语音识别后端默认自动选择：优先用本地 `faster-whisper`（更稳、不需要联网），
装不上再退回 `speech_recognition` 的 Google 后端。也可以 `--mode text` 用打字
代替说话。

关键词解析已经处理了「不要前进」「别左转了」这类否定句（不动作），以及
「向左转的反方向」（等于右转）这种反向说法。

姿态识别做了模糊匹配：支持「姿态/姿势/位姿/自拍/字台/紫台」等语音误识别，
以及中文数字和常见同音字（例如「五/武/伍/午」都当成 5）。

如果还要更“智能”，可以加 `--llm`，关键词匹配不到时调用 OpenAI 兼容接口做
自然语言解析。支持 DeepSeek（推荐，配置 `DEEPSEEK_API_KEY`）和任意 OpenAI
兼容接口（配置 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`）。

## 三、依赖

```powershell
pip install pyserial faster-whisper SpeechRecognition pyaudio openai zhconv
```

`faster-whisper` 第一次运行会下载语音模型（`--whisper-model`，默认 `small`）。
`zhconv` 用于把 Whisper 常输出的繁体字转成简体，提高关键词命中率。

## 四、使用方法

语音模式：

```powershell
python voice_control.py --port COM5
```

指定后端：

```powershell
python voice_control.py --port COM5 --stt whisper --whisper-model small
python voice_control.py --port COM5 --stt google
```

启用 LLM 兜底：

```powershell
$env:DEEPSEEK_API_KEY = "你的 DeepSeek Key"
python voice_control.py --port COM5 --llm
```

加 `--llm` 后，每条语音会先交给 DeepSeek 理解成结构化动作（更智能，能处理
“合上夹爪”“把爪子闭起来”“抬起来”“收回来”这类抽象说法），LLM 失败时再回退到
本地关键词匹配。

LLM 现在输出的是“动作序列”，不是从预设动作里硬选一个。它可以自由组合
`home / pose / gripper / move / move_to / pause / stop` 这些基础动作来表达
任意新动作，例如“点头”“摇头”“弯腰”都能由它现场编出移动序列。

文字模式（打字代替说话）：

```powershell
python voice_control.py --port COM5 --mode text
```

先不接机械臂预览：

```powershell
python voice_control.py --dry-run --mode text
```

说 / 输入示例：`姿态1`、`挥手`、`向前移动5厘米`、`向上`、`执行动作 1 2 3`。

## 五、说明

- 语音识别只负责「声音 -> 文本」，动作执行完全复用前面的姿态控制和逆运动学控制。
- `挥手` 默认对应姿态序列 `6 7 6 7`，可以在 `voice_control.py` 的 `ACTION_ALIASES`
  里按你们实际录好的姿态修改。
