# 1.2 逆运动学控制（IK）实现说明

## 一、任务目标

根据 so-arm 101 follower 的连杆尺寸，实现逆运动学（Inverse Kinematics，IK），
用键盘 / 文字命令控制末端夹爪做前后、左右、上下直线运动。关节角全部由 IK
计算得出，不是直接指定每个舵机角度。

## 二、运动学模型

正运动学直接使用 lerobot 的 SO101 模型，即 `SO101/so101_new_calib.urdf` 里的
完整连杆链。末端坐标系取 `gripper_frame_link`，和 lerobot 的 `RobotKinematics`
默认目标坐标系一致。

连杆链顺序：

    base_link
      -> shoulder_link   (shoulder_pan)
      -> upper_arm_link  (shoulder_lift)
      -> lower_arm_link  (elbow_flex)
      -> wrist_link      (wrist_flex)
      -> gripper_link    (wrist_roll)
      -> gripper_frame_link  (固定，末端参考点)

每个旋转关节的轴都是其子连杆局部 z 轴，关节角从 URDF 的 `<origin rpy>` 决定。

## 三、正运动学（FK）

每个连杆的位姿由 `<origin xyz rpy>` 和关节角共同决定：

    R_link = R_parent * R_rpy * Rz(angle)
    P_link = P_parent + R_parent * xyz

逐级相乘，最后得到 `gripper_frame_link` 在 `base_link` 系下的位置 (x, y, z)。
这就是「已知关节角求末端位置」。

## 四、逆运动学（IK）

采用数值雅可比 + 阻尼最小二乘，与 lerobot 用 placo 做 IK 的思路一致：

1. 只解三个主动关节：shoulder_pan、shoulder_lift、elbow_flex；
   wrist_flex、wrist_roll、gripper 保持当前值不动。
2. 用有限差分算位置对关节角的雅可比矩阵 J（3x3）：

       J[i][j] = dP_i / dq_j

3. 每一步沿目标方向迭代：

       dq = J^T * (J*J^T + lambda*I)^-1 * (target - P)
       q = clamp(q + dq, q_min, q_max)

4. 重复直到末端位置误差足够小。

这样末端走直线时三个关节会同时、协调地运动，不会出现“只有一个关节转、
末端走斜”的情况。

## 五、舵机步数 <-> 关节角

采用 lerobot 的 DEGREES 归一化公式。`joint_ranges.json` 给出每个关节的
`min_step` 和 `max_step`，取中点作为关节角零点：

    midpoint = (min_step + max_step) / 2
    angle_deg = (step - midpoint) * 300 / (resolution - 1)
    step = round(angle_deg * (resolution - 1) / 300 + midpoint)

SCS215 是 10 bit、300° 位置范围舵机，`resolution = 1024`，因此整个 0~1023
对应 300°（注意不是 STS3215 的 12bit/360°）。

## 六、无解与越界处理

- 每次迭代后都把 q 夹到标定范围对应的关节角限位内。
- 迭代结束时若末端位置误差仍大于 1 mm，打印「IK 无解或未收敛：目标超出可达
  范围，已沿原方向夹到最近可达点」，并使用当前已经尽可能靠近目标的位置。

## 七、使用方法

先预览（不连接舵机）：

```powershell
python ik_control.py --selftest
python ik_control.py --dry-run --move up 0.05
```

连接舵机，一次性让末端移动指定方向和距离：

```powershell
python ik_control.py --port COM5 --move up 0.05
```

或直接给绝对坐标（base 系，单位米）：

```powershell
python ik_control.py --port COM5 --goto 0.39 0 0.23
```

交互模式（文字 / 数字 / 中文）：

```powershell
python ik_control.py --port COM5
```

| 命令 | 含义 |
|---|---|
| `up 0.05` / `向下移动5厘米` | 向上移动 5 cm |
| `forward 0.03` / `向前3厘米` | 向前移动 3 cm |
| `left 0.02` / `左移2厘米` | 向左移动 2 cm |
| `move 0 0.05 0` | 相对位移 (x, y, z)，单位米 |
| `goto 0.39 0 0.23` | 绝对坐标，单位米 |
| `i` / `q` | 显示位置 / 退出 |

键盘控制模式：

```powershell
python ik_control.py --port COM5 --mode keyboard
```

`w/s` 前后，`a/d` 左右，`r/f` 上下，方向键 `↑↓←→` 也可用，`q` 退出。

## 八、自测结果

`python ik_control.py --selftest` 的结果：

- 零位末端参考点约为 (0.3914, 0.0000, 0.2265) 米。
- 200 个随机点 FK -> IK -> FK 往返最大位置误差 0.000 mm。
- 「向上 5 cm」测试：实际位移 x = -0.00 cm、y = +0.00 cm、z = +5.00 cm，
  说明末端确实沿竖直方向走直线。

## 九、上真机前的检查

首次接真机先小步动一下，确认每个关节运动方向正确。若某个关节方向反了，
把该关节的 `min_step` 和 `max_step` 对调（或在校准文件里交换两值）即可。
