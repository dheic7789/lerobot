# 运行说明

## 环境

```powershell
cd "C:\Users\chenxianzhang\Desktop\具身智能\期末作业-弹钢琴"
$PY = "D:\lerobot\.venv\Scripts\python.exe"
```

## 检查舵机

```powershell
& $PY .\diagnose_servo_ranges.py --port COM5
```

关闭全部扭矩：

```powershell
& $PY .\release_all_torque.py --port COM5 --confirm
```

## 重新示教七个音键

```powershell
& $PY .\teach_piano_joint.py --port COM5 --confirm
```

记录统一抬起位 `h`，再依次按下 `1～7` 并输入对应数字，最后输入 `f` 保存。

只修改某个音键：

```powershell
& $PY .\teach_piano_joint.py --port COM5 --notes 1 `
  --output .\config\piano_joint_poses.json --update-existing --confirm
```

## 演奏

单个音：

```powershell
& $PY .\piano_joint.py --note 1 --port COM5 --confirm
```

完整《小星星》：

```powershell
& $PY .\piano_joint.py --melody twinkle_full --port COM5 --confirm
```

完整《哈巴狗》：

```powershell
& $PY .\piano_joint.py --melody habagou --port COM5 --confirm
```

推荐稳定参数：

```powershell
& $PY .\piano_joint.py --melody twinkle_full --port COM5 --confirm `
  --move-seconds 0.30 --press-seconds 0.15 --dwell-ms 60 `
  --beat-ms 650 --initial-seconds 1.8 --max-joint-speed 160 `
  --max-move-attempts 3 --speed 180 --approach-lift-steps 60
```
