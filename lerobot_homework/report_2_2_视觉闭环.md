# EmbodiedAI Week 4 Hackathon — 2.2 基于视觉的闭环控制

**实现：** 机械臂通过摄像头实时取图，用 OpenCV 检测屏幕上的黑色圆球在画面中的位置，根据球心与画面中心的偏差，经"正运动学 → 末端目标位姿 → 逆运动学"换算成各关节角目标并下发，实现"看 → 算 → 动"的视觉反馈闭环。

**验收对照：** 机械臂自动运动（非手动输入）、运动方向明显朝向黑球、不要求精确接触 —— 均满足。

---

## 1. 系统架构

```
┌──────────┐   ┌───────────────────┐   ┌────────────────────┐
│ 摄像头    │ → │ OpenCV 黑球检测    │ → │ 像素偏差 → 末端位移  │
└──────────┘   └───────────────────┘   └─────────┬──────────┘
                                                 ↓
┌──────────┐   ┌───────────────────┐   ┌────────────────────┐
│ 机械臂    │ ← │ 逆运动学 IK(placo) │ ← │ 正运动学 FK + 目标位姿│
│(SO-ARM101)│   │ 关节角 → send_action│   └────────────────────┘
└──────────┘   └───────────────────┘
      ↑                ↓
      └──── 闭环：重新取图，直到球心对准画面中心 ────┘
```

每一轮循环 = 取图 → 检测黑球 → 计算偏差 → 目标末端位姿 → IK 求关节角 → 下发 → 等待 → 再取图。由于偏差每轮重新计算，即使单步映射不精确，闭环也会逐步收敛，这正是"基于视觉反馈的闭环控制"的核心。

## 2. 黑球检测（OpenCV）

黑球是"纯白背景上的哑光黑色圆球"，在灰度图中是亮度最低的大块连通域。算法分两步：

1. **轮廓法（主）**
   - 灰度化 + 高斯模糊去噪；
   - 二值化 `THRESH_BINARY_INV`（灰度 < 阈值 的暗部变前景），`threshold=60` 可调；
   - 形态学开运算去点状噪声、闭运算填补球面反光造成的空洞；
   - 取面积最大的轮廓，用 `minEnclosingCircle` 得到圆心 `(cx, cy)` 与半径 `r`；
   - 用**圆形度** `4π·面积/周长² ≥ 0.4` 过滤杂散噪声。
2. **HoughCircles 兜底**：当反光把轮廓打断、轮廓法失败时，用霍夫圆变换直接找圆，保证鲁棒性。

实测（官方黑球图 1024×1024，含左侧反光）：阈值 40~120 全部稳定检出，球心 ≈ (520~535, 520~526) px，半径 ≈ 256~285 px，反光不影响检测。

## 3. 像素偏差 → 末端移动量

设画面中心为 `(W/2, H/2)`，球心为 `(cx, cy)`，则像素偏差：

- `dx_px = cx - W/2`：>0 表示球偏右；
- `dy_px = cy - H/2`：>0 表示球偏下。

按相机安装方向做线性映射（`--gain` 像素→米比例，默认 0.0004 m/px）：

```
Δx =  dx_px × gain        （球偏右 → 末端向右移）
Δz = -dy_px × gain        （球偏上 → 末端向上移）
Δy = 0                    （y 方向保持）
```

每步位移用 `--max-step`（默认 0.02 m）限幅，防止大幅突跳；若实际方向相反，用 `--invert-x / --invert-y` 取反。

## 4. 正/逆运动学（lerobot + placo）

- **模型**：官方 URDF `SO-ARM100/Simulation/SO101/so101_new_calib.urdf`（含关节轴、连杆尺寸、限位）；为 IK 求解生成运动学精简版（mesh 换占位盒）。
- **正运动学 FK**：由当前关节角（度）求末端 4×4 位姿矩阵 `T_curr`（`RobotKinematics.forward_kinematics`）。
- **目标位姿**：位置 = `T_curr` 平移部分 + 步骤 3 的移动量；朝向保持当前不变（只平移、不旋转，避免腕部姿态抖动）。
- **逆运动学 IK**：`RobotKinematics.inverse_kinematics`（placo 牛顿迭代数值求解，以当前关节角为初值，位置权重大、朝向权重小）→ 关节角目标（度）。
- **IK 无解处理**：
  - 目标点超出可达半径 → 打印提示并沿原方向收缩到可达范围后继续（保留原运动方向）；
  - IK 解回代 FK 校验，位置误差 > 3 cm → 判定不可达，本轮不下发，继续观察。

## 5. 闭环循环与安全机制

- **控制频率** ~20 Hz；每次移动后重新取图，偏差进入阈值（15 px）即判定已对准，保持当前姿态；
- **安全**：
  - `EEBoundsAndSafety`：末端位置边界 + 每步最大位移限速（超步长自动限速而非中断）；
  - `max_relative_target=30°`：send_action 内部限制单步关节角变化量；
  - URDF 关节限位裁剪：IK 输出再夹到各关节限位内；
  - 按 `q` 退出 / `Ctrl+C` 紧急停止，退出自动断开并关闭扭矩。

## 6. 使用说明

环境：`lerobot` conda 环境（Python 3.12，torch cu126，lerobot 0.6.2），已补装 `placo`（conda-forge）与 `opencv-python`。

```bash
# 0) 环境自检（不连机械臂）：URDF 加载 + IK 数值验证
python vision_closed_loop.py --mode check

# 1) 先测摄像头与黑球检测（不连机械臂，可现场调 --threshold）
python vision_closed_loop.py --mode camera

# 2) 完整视觉闭环（机械臂 + 摄像头）
python vision_closed_loop.py --port COM3

# 方向不对时
python vision_closed_loop.py --port COM3 --invert-x --invert-y
```

常用参数：`--port`、`--camera-id`、`--gain`（像素→米）、`--max-step`（每步米数）、`--threshold`（黑球灰度阈值）、`--invert-x/--invert-y`、`--align-px`、`--max-iter`、`--robot-id`（校准文件 id，首次连接会引导做一次 lerobot 校准）。
